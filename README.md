# ELINSZ 3DS

**ELINSZ 3DS** é um plugin para SketchUp voltado à marcenaria e design de interiores. Ele oferece uma biblioteca de componentes, sistema de acabamentos e acessórios de montagem com interface interativa.

## 🧩 Funcionalidades

- Inserção de componentes (.skp) diretamente no modelo
- Troca de acabamentos com texturas (.jpg)
- Cadastro dinâmico de novos acabamentos e acessórios
- Interface HTML com integração Ruby/JavaScript

## 📁 Estrutura

- `componentes/`: modelos 3D (.skp)
- `acabamentos/`: texturas (.jpg)
- `acessorios/`: acessórios de montagem (.skp)
- `data/`: arquivos JSON com os cadastros
- `uploads/`: arquivos enviados pelo usuário
- `ui/`: interface HTML, CSS e JS
- `elinsz_3ds.rb`: script principal do plugin

## 🚀 Instalação

1. Compacte a pasta como `.zip` e renomeie para `.rbz`
2. No SketchUp: `Extensões > Instalar extensão...`
3. Selecione o arquivo `.rbz`

## 🛠 Requisitos

- SketchUp 2017 ou superior
- Ruby 2.x (incluso no SketchUp)
- Permissões para instalar extensões
